# TCP/IP Encapsulation Activity: Role Cards #

## Application Layer ##

**Role:** Create or receive the original application data.

### Sending Procedure ###

- **Input:** None
- **Output:** Original item and destination address

1. Create the original item or message.
2. Identify the destination address.
3. Pass the item/message and destination address to the Transport Layer.

- **Report:** "Application Layer created the data and passed it to the Transport Layer with the destination address."

### Receiving Procedure ###

- **Input:** Original item from the Transport Layer
- **Output:** None

1. Receive the original item/message from the Transport Layer.
2. Confirm that the application data has been delivered.

- **Report:** "Application Layer received data from the Transport Layer."
