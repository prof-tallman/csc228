# Reading Guides #

Prof. Tallman has created a series of guides to set the context for each assigned reading and help you look for important concepts. These notes should help prepare you for quizzes and writing assignments. Some guides cover several chapters at once. Depending on the reading schedule, you may use the same guide for multiple class sessions.
